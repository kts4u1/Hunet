# 휴넷 자동 학습 (필립스)

`https://philips.hunet.co.kr` 에 자동으로 로그인해서, **나의 강의실**에서 현황이 100%가 아닌 과정의 **학습창**을 열어 주는 Windows 프로그램입니다.

## 동작 순서

1. 프로그램 첫 화면에서 **아이디**(`philips-숫자`, 숫자만 넣어도 `philips-`가 붙음)와 **비밀번호** 입력 후 **[로그인하고 학습 시작]**
2. Microsoft Edge(없으면 Chrome)가 열리고 로그인 페이지에 아이디/비밀번호를 입력해 로그인
   - 본인인증(인증번호)을 요구하면 프로그램이 입력 창을 띄웁니다.
3. 메인 화면의 **학습하기** 클릭 → **나의 강의실(진행중 교육)** 으로 이동
4. 과정 목록에서 **현황**을 확인해 100%가 아닌 첫 번째 과정의 **관리 → 학습하기** 클릭
5. **학습창(새 창)** 이 열리면 앞으로 띄우고 대기합니다. (모든 과정이 100%면 학습창을 열지 않음)

프로그램 왼쪽의 **진행 단계**에서 지금 어느 단계인지(진행 중 / 완료 ✓ / 오류 !) 볼 수 있고, 아래 **진행 기록**에 자세한 내용이 표시됩니다.
브라우저를 닫거나 프로그램의 **[중지]** 를 누르면 끝납니다.

## 자동 로그인

- **"다음 실행부터 자동 로그인"** 스위치를 켠 상태로 로그인에 성공하면 정보가 저장되고, **다음 실행부터 3초 뒤 자동으로 로그인**합니다. (카운트다운 중 [취소]를 누르면 취소)
- 비밀번호는 **Windows 자격 증명 관리자**에 암호화되어 저장됩니다. 아이디/설정은 `%APPDATA%\HunetAutoStudy\settings.json`에 저장됩니다.
- 비밀번호가 바뀌어 자동 로그인이 실패하면, 계정 잠김을 막기 위해 **자동 로그인을 자동으로 해제**합니다. 새 비밀번호를 입력하고 다시 시작하면 됩니다.
- **[저장 정보 삭제]** 로 저장된 아이디/비밀번호를 지울 수 있습니다.

## 실행 방법

### 방법 1. exe 파일 (Python 필요 없음)

- GitHub 저장소의 **Actions → "Windows EXE 빌드"** 에서 최근 실행을 열고, 맨 아래 **Artifacts** 의 `HunetAutoStudy-windows` 를 내려받아 압축을 풀면 `HunetAutoStudy.exe` 가 있습니다.
- 또는 Python 이 설치된 PC 에서 `build_exe.bat` 를 실행하면 `dist\HunetAutoStudy.exe` 가 만들어집니다.

### 방법 2. Python 으로 바로 실행

1. [Python](https://www.python.org/downloads/) 설치 (설치 화면에서 **Add python.exe to PATH** 체크)
2. 이 폴더의 `run.bat` 더블클릭 (처음 한 번은 필요한 패키지를 설치하느라 1~2분 걸립니다)

> 브라우저는 PC 에 설치된 **Microsoft Edge** 를 사용합니다. 따로 내려받을 것은 없습니다.

## 문제가 생기면

- 마지막 실행 기록이 `%APPDATA%\HunetAutoStudy\last_run.log` 에 저장됩니다. (탐색기 주소창에 `%APPDATA%\HunetAutoStudy` 입력)
- 사이트 화면 구성이 바뀌어 버튼을 찾지 못하면, 프로그램이 브라우저를 닫지 않고 그대로 두므로 직접 이어서 진행할 수 있습니다.

## 개발자용

```
hunet_auto/
  app.py     프로그램 화면 (tkinter)
  bot.py     사이트 자동 조작 (Playwright)
  config.py  아이디/비밀번호 저장
tests/
  mock_site.py  실제 화면 구조를 흉내 낸 테스트용 가짜 사이트
  test_flow.py  로그인 → 나의 강의실 → 학습창 열기 흐름 테스트
```

테스트 실행: `python tests/test_flow.py`
